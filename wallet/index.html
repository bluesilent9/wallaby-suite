Trust stays local.

A match confirms that the required devices agree. It does not establish that a transaction is safe. Keep checking the wallet, destination, amount and vault policy on each Agent before approving.

The mobile and Agent interfaces use separate SSH-loopback ports: 56444 for mobile verification and 56443 for Agents. No certificate administration or public mobile HTTP port is needed.
