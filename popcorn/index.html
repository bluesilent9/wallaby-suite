          Do I need Jellyfin?

          Yes. The Wallaby Popcorn apps connect to your own Jellyfin server. The server web fork changes its supplied interface. This is not a streaming subscription or a source of films. SSH access and the server-side enrolment setup are required when using the built-in tunnel.

          How do updates work?

          The forks retain their Jellyfin upstream history and version conventions. Upstream changes are incorporated manually when the project is ready. Mobile Stable and Development, desktop Development, Android TV Development and server web have separate links above.
